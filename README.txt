PfeifenLoki Styles – Fabric GUI-Prototyp
Minecraft Java 1.21.11 | F9 | dunkles Minecraft-inspiriertes GUI mit Lila

Diese Version ersetzt das einfache Button-Menue durch eine Seitenleiste,
Style-Kacheln und anklickbare Kategorien/Style-Auswahl.

WICHTIG: Die Vorschau-Kacheln sind derzeit Platzhalter-Grafiken.
Es sind noch keine echten Minecraft-Item-Texturen oder In-Game-Reskins enthalten.
Dies ist Quellcode, keine fertig kompilierte/getestete JAR.

Build-Voraussetzungen: Java JDK 21, Gradle und Internetzugang.
Im Projektordner: gradle wrapper
Dann: ./gradlew build (Windows: gradlew.bat build)
Die JAR erscheint in build/libs/.
